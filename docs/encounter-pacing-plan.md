# Encounter pacing plan

1. Cache entrance-distance data and expose three deterministic generation bands.
2. Protect the first ten traversable steps from initial NPC placement.
3. replace flat archetype selection with depth-weighted tables and add objective-room minimum guards.
4. Record equipment tier and place a fixed useful loot mix across shallow, middle, and deep bands.
5. Apply depth tier to equipment carried by generated NPCs.
6. Add F1 depth inspection, documentation, broad seeded tests, and runtime smoke checks.
