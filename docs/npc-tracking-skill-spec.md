# NPC tracking skill — brief spec

- Trail-detection range is part of each archetype's immutable awareness profile.
- Wretches and Trolls detect clues within two cardinal cells; Goblins within one; Orcs only underfoot.
- Skeletons cannot interpret physical trails.
- Tracking range changes clue discovery only, not trail lifetime or the evidence an NPC receives from sight, sound, or allies.
- F1 inspection exposes the tracking value with the other awareness traits.
