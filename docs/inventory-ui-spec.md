# Inventory UI — brief spec

- `I` toggles an inventory panel without spending a turn.
- The panel lists all eight slots and highlights the selected item.
- Each occupied slot shows item name, type/power, and whether it is equipped.
- While open, up/down arrows or brackets cycle selection without spending a turn.
- `H`, `E`, and `D` continue to use, equip, or drop the selected item with existing turn costs.
- Movement commands are suppressed while the panel is open.
- The compact HUD remains available during ordinary play.
