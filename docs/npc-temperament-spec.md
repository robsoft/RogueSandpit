# NPC temperament — brief spec

- Each NPC archetype has an immutable awareness profile: sight range, hearing adjustment, ally-alert radius, and persistence adjustment.
- Goblins see well and alert broadly but give up relatively quickly.
- Orcs are persistent and hear combat well, but alert over a smaller area.
- Skeletons hear poorly but retain evidence for a long time.
- Trolls see poorly, hear very well, and pursue clues stubbornly.
- Wretches have modest sight, strong hearing, and average persistence.
- Noise retains its action-specific base radius; the listener's hearing adjustment changes whether that NPC receives it.
- Profiles affect awareness only, leaving existing health, damage, and movement rules unchanged.
